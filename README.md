📩 Contact Form with HTML, CSS & JavaScript Validation

This project is a simple and clean contact form built using HTML, CSS, and JavaScript.
It includes client-side validation for name, email, and message fields.
Users receive instant error messages and success feedback without submitting the form to a server.


---

🚀 Features

✔️ Fully responsive contact form

✔️ JavaScript validation for:

Empty Name

Invalid Email

Empty Message


✔️ Shows success message on valid submission

✔️ Modern UI using CSS

✔️ No backend required

---

🧠 Validation Rules

1. Name must not be empty.


2. Email must match the pattern:

/^[^ ]+@[^ ]+\.[a-z]{2,3}$/


3. Message must not be empty.



If all fields are valid, a success message appears at the top of the form.

🛠️ How to Run

1. Download or copy the project folder.


2. Open the index.html file in any browser:

Chrome

Edge

Firefox

Safari




The form will load instantly — no server required.
